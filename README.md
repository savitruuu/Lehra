# Lehra – Practice Companion

Lehra - Practice Companion is a professional, web-based Lehra (लहरा) player and practice tool for Hindustani classical musicians. It features real-time melodic loops across authentic Raags, Taal cycle visualizer, realistic sampled instruments (Harmonium, Santoor, Sitar, Piano, Guitar), Tanpura, metronome, Tabla, Swarmandal accompaniment, and practice analytics for focused daily Riyaaz.
