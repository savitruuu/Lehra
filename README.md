# Lehra – Tabla Practice Companion

Lehra is a professional-quality, browser-based Lehra (लहरा) player and practice tool for Hindustani classical musicians. It features real-time melodic loops across authentic Raags, synced visual Taal tracking with the Avartan Chakra ring, realistic sampled instruments (Harmonium, Santoor, Sitar, Piano, Guitar), recorded Tanpura drone, metronome, Tabla theka accompaniment, and practice analytics for focused daily Riyaaz.

The app is a MERN stack application: a React frontend (`client/`, built with Vite) and an Express + MongoDB API (`server/`) that handles optional user accounts. See [MERN.md](MERN.md) for how the two pieces fit together and how to run them, and [DEPLOY.md](DEPLOY.md) for deployment. The pre-MERN single-page implementation is kept for reference in [Non-MERN/](Non-MERN/) but is no longer built or deployed.
