# Lehra – Tabla Practice Companion

Lehra is a professional-quality, browser-based Lehra (लहरा) player and practice tool for Hindustani classical musicians. Built as a pure client-side web application using HTML, CSS, JavaScript, and the Web Audio API, it features real-time melodic loops across authentic Raags, synced visual Taal tracking with the Avartan Chakra ring, realistic sampled instruments (Harmonium, Santoor, Sitar, Piano, Guitar), recorded Tanpura drone, metronome, Tabla theka accompaniment, and practice analytics for focused daily Riyaaz.
